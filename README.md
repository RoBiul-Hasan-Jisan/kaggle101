# Kaggle101 
> **Learning, Experimentation & Kaggle Practice Repository**

This repository contains my Kaggle competition experiments, practice notebooks, and exploratory projects. The main goal of this repository is learning, experimentation, and improving machine learning skills, not building production-ready applications.

Unlike my other repositories where I build complete applications (Streamlit, Flask, production pipelines, etc.), this repository is intentionally lightweight and focused on practice and exploration.

---

##  Purpose of This Repository
* Practice Kaggle competitions
* Experiment with different datasets
* Learn machine learning workflows
* Perform EDA (Exploratory Data Analysis)
* Test model ideas and techniques
* Improve data science intuition

**Projects here may include:**
* Kaggle competition solutions
* Experiments with public datasets
* Quick model prototypes
* Data exploration notebooks
* Random ML experiments for learning

*Note: This repository is mainly about learning and having fun with data!*
